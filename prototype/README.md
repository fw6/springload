# 页面与交互原型（一次性）

这个目录是「页面与交互原型」ticket 的产物：八个页面长什么样、每一步给什么解释，用三个可以切换的界面变体摆出来供挑选。分支 `prototype/pages`，不合并回主干。

## 跑起来

```sh
cd prototype
npm install
npm run dev
```

打开 http://localhost:5199/ 。

## 三个变体

底部中间有一条切换条，左右箭头或键盘 `←` `→` 切换；变体写在地址栏的 `?variant=A|B|C`，可以直接分享链接。生产构建里这条切换条不出现。

| 变体 | 密度 | 图表与面板 | 解释方式 |
| --- | --- | --- | --- |
| A | 行高 28px，正文 12.5px | 62 : 38 | 悬停：术语下面带虚线，鼠标停上去弹出白话解释 |
| B | 行高 44px，正文 15px | 38 : 62 | 弹窗：术语是虚线标签，点一下弹出一整屏说明；每步还有一个「这一步在干什么」按钮 |
| C | 行高 36px，正文 14px | 55 : 45，面板可收起 | 内联：控件下面常驻一行白话说明，点「展开」看完整版 |

变体是全局的，五个路由都跟着变。

## 五个路由

主流程做成一页四步（顶部四步进度、左侧 K 线图、右侧当前步骤的面板）：

1. **强势股筛选** —— 阈值输入组加候选池表格，表头可按涨幅和排名排序，四条判定 C1~C4 逐列显示，点一行就选中该股票。
2. **标注支撑区** —— 图上工具栏有水平线、支撑区、跳空缺口、AVWAP 起点四个工具。支撑区是拖两次点出一个矩形，水平线点一下放一条。已经画好的矩形和水平线可以用鼠标拖动，拖动后置信度实时重算。面板列出每条标注的下沿、上沿、置信度，以及三个参考价（EMA21、AVWAP、前期高点）各自落在几个框内。
3. **等待买入信号** —— 图表切到 1 分钟周期，列出前置条件与触发条件是否满足，「模拟触发信号」把状态推到已触发。
4. **算仓位与目标位** —— 买入价、止损价、账户金额、单笔风险比例四个输入，公式逐项列出，股数按 A 股一手 100 股向下取整，结果卡给出股数、投入金额、仓位占比、止损距离、3R 与 5R 目标位，并给出三种校验提示。

另外四个路由：`/plan` 计划卡、`/positions` 持仓跟踪、`/journal` 交易日志、`/settings` 设置。

四步有先后依赖：没有观察名单进不了第 2 步，没有高置信支撑区进不了第 3 步，没有触发信号进不了第 4 步。未解锁的步骤在顶部是灰的，点不动。

## 支撑区置信度怎么算

AVWAP、EMA21、前期高点三个价格的最大值与最小值之差除以三者的均值，落在 2% 以内算高置信，5% 以内算中置信，其余算低置信。一条支撑区还要有两个以上参考价落在框内，才算真正的高置信。默认选中的紫金矿业三个参考价离散度约 1.3%，所以打开就是高置信，第 3 步是解锁的。

## 数据都是假的

不联网。行情由 `src/data/market.ts` 里的种子函数生成，每只股票按「主升 → 第一次回踩 → 反弹 → 回落进整理区 → 下探 → 收尾」六个阶段拼出一条 120 根日线的曲线，形状参数写在 `src/data/stocks.ts` 的种子表里：`gain` 决定近 6 个月涨幅，`tightness` 决定整理区宽度（也就是 C2 波动收敛判定看的东西），`endDrift` 决定收尾强弱（也就是 C3 均线判定看的东西）。筛选表格里的每一列都是从这条曲线上算出来的，跟图表看到的是同一份数据。

计划卡、持仓、交易日志里的数字是写死的示例。AI 解释段落是占位文案，措辞只描述形态与位置，不给买卖结论。

## 这个原型不负责什么

不做自动交易、不做回测、不做荐股。没有后端、没有持久化、没有测试，状态全在内存里，刷新就回到初始。所有控件里只有主流程那四个输入框是真的能改并触发重算的，其余按钮是占位。
