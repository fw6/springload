# Triage 标签

各技能用五个标准 triage 角色交流。本文件把这些角色映射到本仓库 issue tracker 里实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库中的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估该 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整描述，可以交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当某个技能提到某个角色（例如「apply the AFK-ready triage label」）时，使用本表里对应的标签字符串。

如果实际使用的名称不同，修改「本仓库中的标签」这一列。
